# 🏰 Realm of Ages — The Eternal War

Asynchronous browser-based MMORPG. Five factions, dual resource economy (gold + mana), real-time turn regeneration, persistent multiplayer.

---

## ⚡ Local Setup (5 minutes)

### Prerequisites
- **Node.js 18+** — download at https://nodejs.org (LTS version)
- **Git** — download at https://git-scm.com

### Steps

```bash
# 1. Clone or copy the project folder, then enter it
cd realm-of-ages

# 2. Install dependencies
npm install

# 3. Create your environment file
cp .env.example .env
# Open .env in any text editor — the defaults work for local dev, no changes needed

# 4. Initialize the database (creates realm.db)
npm run db:init

# 5. Start the development server
npm run dev

# 6. Open your browser
#    http://localhost:3000
```

The server auto-restarts when you edit files (nodemon). The SQLite database file `realm.db` is created automatically in the project root.

## 🌐 Deploying to Production (Railway — Recommended)

Railway is the easiest free-tier host. No credit card needed to start.

### Step 1 — Push to GitHub

```bash
# In your project folder:
git init
git add .
git commit -m "Initial commit"

# Create a new repo at github.com, then:
git remote add origin https://github.com/YOUR_USERNAME/realm-of-ages.git
git push -u origin main
```

### Step 2 — Deploy on Railway

1. Go to **https://railway.app** and sign in with GitHub
2. Click **New Project → Deploy from GitHub repo**
3. Select your `realm-of-ages` repository
4. Railway auto-detects Node.js and runs `npm start`

### Step 3 — Add PostgreSQL (for real multiplayer)

1. In your Railway project, click **New → Database → PostgreSQL**
2. Go to your app service → **Variables** tab
3. Add these environment variables:
   ```
   NODE_ENV=production
   SESSION_SECRET=<generate a long random string>
   DATABASE_URL=<copy from the PostgreSQL service's "Connect" tab>
   ```
4. Railway auto-redeploys. Your game is now live at `https://yourapp.railway.app`

### Generating a SESSION_SECRET

Run this in any terminal:
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
```

## 🚀 Alternative Hosting Options

### Render (also free tier)
1. Go to **https://render.com**, connect GitHub
2. New → Web Service → your repo
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Add environment variables in the Render dashboard
6. Add a PostgreSQL database from Render's dashboard

### Fly.io (more control, free tier available)
```bash
npm install -g flyctl
flyctl auth login
flyctl launch
flyctl postgres create
flyctl secrets set SESSION_SECRET=<your-secret> NODE_ENV=production
flyctl deploy
```

## 🎮 Game Systems

- **Turns** — Accrue 1 per 2 minutes, capped at 200. Spent on exploring, building, recruiting, and battling.
- **Gold** — Generated by land (1.5g/hr per acre) and buildings (8–50g/hr). Consumed by army upkeep.
- **Mana** — Generated by land (0.8m/hr per acre) and arcane buildings (3–55m/hr). Heavy units are mana-hungry.
- **Power** — `(land × 2) + (buildings × 50/level) + unit power totals`. Used for battle calculations and rankings.
- **Battle** — Win chance based on power ratio. Victory: +15% enemy gold, +10% enemy mana, land seizure.
